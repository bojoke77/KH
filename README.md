# 작품 이름

## 나랑 어울리는 걸?

> 한 줄 소개: 여러 가지 질문에 답하면 나와 가장 잘 맞는 여자아이돌을 찾아 주는 앱입니다.

  > AI 최애 매칭기

## 1. 개발 의도

평소에 친구들과 아이돌 이야기를 자주 하는데 나와 가장 잘 맞는 아이돌은 누구일까?라는 생각이 들어 이 앱을 만들게 되었습니다.

단순히 결과만 보여 주는 것보다 직접 질문에 답하고 럭키박스를 선택하는 과정을 넣으면 더 재미있을 것 같았습니다. 

친구들과 결과를 비교하고 순위를 확인할 수 있도록 만들어 모두 함께 즐길 수 있는 앱을 만들고 싶었습니다.

친구들이 입력한 결과를 Top12 순위로 볼 수 있게 하여 우리 반에서 어떤 아이돌이 인기 있는지도 확인할 수 있도록 했습니다.

## 2. 적용 대상

- 사용 대상: 여자아이돌에 관심있고 나와 매칭율이 궁금한 학생 

- 사용 상황: 쉬는 시간에 친구들과 아이돌 취향을 비교할 때

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |

| --- | --- |

| 참가자 정보 입력 | 이름, 학년, 반, 번호를 입력합니다. |

| 랜덤 질문 | 15개의 질문 중 10개가 랜덤으로 나옵니다. |

| 아이돌 매칭 | 답변을 바탕으로 나와 잘 맞는 아이돌을 찾아 줍니다. |

| 럭키박스 | 결과를 보기 전에 점수 보너스를 받을 수 있습니다. |

| Top12 순위 | 참가자들의 매칭률과 최애 아이돌 순위를 보여 줍니다. |

| 관리자 기능 | 관리자가 참가 기록을 수정하거나 초기화할 수 있습니다. |

| QR 결과 | 결과 정보를 QR 코드로 저장하고 다른 기기에서 볼 수 있습니다. |

**사용 방법**

1. 앱 주소에 접속합니다.

2. 나만의 최애 찾기 버튼을 누릅니다.

3. 이름, 학년, 반, 번호를 입력합니다.

4. 화면에 나오는 10개의 질문에 답합니다.

5. 럭키박스 3개 중 하나를 선택합니다.

6. 분석이 끝나면 나의 최애 아이돌과 매칭률을 확인합니다.

7. 결과를 QR 코드로 확인하거나 이미지 파일로 저장합니다.

## 4. 기대 효과

친구들과 서로의 취향을 쉽고 재미있게 비교할 수 있습니다. 

Top12 순위를 보면서 우리 반에서 인기 있는 아이돌도 알 수 있습니다.

## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구**: ChatGPT

- **처음에 AI에게 한 요청(프롬프트)**:

  > 중학교 학생들이 재미있게 사용할 수 있는 최애 여자아이돌 찾는 프로그램을 만들어 줘. 

이름, 학년, 반, 번호를 입력하고 여러 질문에 답하면 나와 가장 잘 어울리는 여자아이돌을 알려 주는 index.html파일을 만들어 줘. 

휴대폰과 노트북에서 모두 사용할 수 있게 해 주고 결과 화면에는 아이돌 이름과 매칭률이 나오게 해 줘.

- **AI가 만든 결과에서 내가 고치거나 추가한 부분**:
처음에는 AI가 만들어 준 기본 기능만 있었지만 친구들이 더 재미있게 사용할 수 있도록 직접 생각하고 여러 가지 기능을 추가했습니다.

1) 처음 화면이 너무 단순해서 친구들의 관심을 끌 수 있도록 전체 참가자 수와 최고 매칭률을 보여 주도록 했습니다.

2) 12명의 아이돌을 골라 친구들과 결과를 비교할 수 있도록 Top12 순위 기능을 추가했습니다.

3) 질문이 15개라서 시간이 오래 걸릴 것 같아 10개만 무작위로 나오도록 바꾸었습니다.

4) 결과 화면에 이름, 학년, 반, 번호가 함께 보이도록 추가했습니다.

5) 아이돌 이름과 매칭률만 나오면 재미없을 것 같아서 아이돌 유형과 나와 잘 어울리는 이유도 보여 주도록 했습니다.

6) 재미를 더하기 위해 럭키박스 기능을 추가했습니다.

7) 럭키박스의 점수가 너무 많이 올라가면 공정하지 않을 것 같아서 보너스 점수는 최대 5%까지만 받을 수 있도록 수정했습니다.

8) 같은 이름으로 여러 번 참여하는 것을 막기 위해 중복 참가 확인 기능을 추가했습니다.

9) 매칭률이 같은 경우 순위가 계속 바뀌는 문제가 있어서 먼저 한 사람이 우선되도록 기준을 만들었습니다.

10) 테스트를 하면서 잘못된 참가 기록을 지울 필요가 생겨 관리자 페이지를 만들었습니다.

11) 아무나 접근하지 못하도록 관리자만 사용할 수 있도록 비밀번호 기능도 추가했습니다.

12) 휴대폰, 크롬북, 노트북 등 화면 크기가 달라도 보기 편하도록 화면이 자동으로 조절되게 만들었습니다.

13) 현재 몇 번째 문제를 풀고 있는지 알 수 있도록 진행률 표시 기능을 추가했습니다.

14) 다시하기 버튼을 누르면 처음부터 새로 시작할 수 있도록 수정했습니다.

15) 관리자 창 바깥을 클릭해도 창이 닫히도록 편리하게 수정했습니다.

16) 결과를 친구들과 공유할 수 있도록 QR 코드 기능과 이미지 저장 기능을 추가했습니다.

17) Github에 파일을 올리고 휴대폰으로 해보니 참가자 정보가 없는걸 확인되어 어느 기계에서 해도 참가기록이 될 수 있도록 firebase를 활용해보았습니다.

- **어려웠던 점과 해결한 방법**:
프로그램을 만들면서 생각보다 여러 가지 문제가 생겼습니다. 처음에는 잘 몰랐지만 AI에게 질문하고 직접 테스트하면서 하나씩 해결했습니다.

1) 처음에는 index.html 하나의 파일에 모두 들어 있어서 내용이 길어서 AI가 답변을 잘 못해주는 경우가 있었습니다. AI가 해결방법으로 파일을 나누는 것을 제안해줘서 파일을 기능별로 나누어 작업을 했습니다.

2) 컴퓨터에서는 괜찮았지만 휴대폰에서는 화면이 이상하게 보였습니다. AI에게 물어보니 반응형 디자인을 적용하면 된다고 해서 수정했습니다.

3) 다시하기를 눌러도 럭키박스 효과가 남아 있는 오류가 있어 AI에게 문제점을 알려주고 수정했습니다.

4) 매칭률이 같은 친구들의 순서가 계속 달라졌습니다. 먼저 참여한 사람이 앞에 오도록 순위 기준을 정해서 해결했습니다.

5) 여러 번 테스트해 보니 특정 아이돌만 계속 선택되는 현상이 있었습니다. 질문별 점수를 확인하고 조정하면서 결과가 골고루 나오도록 수정했습니다.

6) 관리자 기능을 만들었을 때 일반 사용자도 접근할 수 있는 문제가 있어 비밀번호 기능을 추가했습니다.

7) 모바일에서는 버튼이 너무 작아서 누르기 어려웠는데 버튼 크기와 간격을 조정하여 해결했습니다.

8) 처음에는 결과 화면이 단순해서 재미가 부족했습니다. 아이돌 유형, 매칭 설명, 순위 기능을 추가하여 더 흥미롭게 만들었습니다.

9) 테스트한 결과를 제거하기 위해 관리자 페이지에 데이터 초기화 기능을 추가했습니다.

10) 질문 수가 많아서 지루할 수 있다고 생각되었습니다.랜덤 출제 방식으로 변경하여 참여 시간을 줄였습니다.

11) 깃허브에 파일을 올리고 접속을 해보니 참가자 기록이 되지 않는 것을 알아 AI에게 물어보니 firebase를 통해 가능하다고 가이드를 받아 적용했습니다.
    firebase는 처음 들어보는 프로그램이라 사용 방법을 이해하기 어려웠습니다. AI가 알려 주는 순서대로 따라 했지만 한 번에 해결되지 않았습니다.
    오류가 발생할 때마다 화면을 캡처해서 AI에게 보여 주고 다시 설명을 들으면서 여러 번 수정한 끝에 해결할 수 있었습니다.

## 8. 개발자 한마디

처음에는 질문에 답하면 나와 가장 잘 어울리는 여자 아이돌을 알려 주는 간단한 프로그램을 만들려고 했습니다.

처음에는 AI에게 부탁하면 프로그램이 금방 완성될 줄 알았습니다. 하지만 막상 만들어 보니 생각하지 못했던 오류도 많았고 원하는 기능을 추가하는 것도 쉽지 않았습니다.

프로그램을 만들다 보니 친구들이 더 재미있게 사용할 수 있도록 해 주고 싶었습니다. 그래서 럭키박스, TOP 12 순위, QR 코드 기능을 하나씩 추가했습니다.

특히 QR 코드는 만들기 어려울 것이라고 생각했는데 AI에게 물어보니 생각보다 쉽게 만들 수 있었습니다. 제가 원하는 기능을 설명하자 AI가 코드를 만들어 주었고 실제로 작동하는 것을 보니 정말 신기했습니다.

코딩을 잘 모르는 상태에서 시작했지만 AI에게 제가 생각한 아이디어를 설명하고 코드를 수정하면서 조금씩 프로그램을 완성할 수 있었습니다. 

오류가 생기면 여러 번 질문하고 테스트하면서 해결했고 원하는 결과가 나올 때까지 수정하는 과정도 재미있었습니다.

앞으로는 더 많은 아이돌 정보를 추가하고 새로운 재미있는 기능도 만들어 보고 싶습니다.

친구들이 이 프로그램을 재미있게 사용하고 서로 결과도 비교하면서 즐거운 추억을 만들었으면 좋겠습니다!
